`build/` 是开发机的编译与运行目录；`test-results/` 是验证产物；`dist/` 是发给其他人的成品。三个目录都不提交 Git。不要直接发送整个 build/。

## 分发步骤

1. 构建 x64 Release，输出仍为 `build/MusicPlayer2.exe`。
2. 双击仓库根目录的 `package.bat`，成功或失败都会暂停并显示结果。
3. 分发 `dist/MusicPlayer2.zip`，可同时提供 `dist/MusicPlayer2.zip.sha256`。
4. 接收者解压整个 ZIP，打开其中 `MusicPlayer2/MusicPlayer2.exe`。DLL、language、skins 等文件要与程序一起保留。

命令行等效入口为 `powershell -NoProfile -ExecutionPolicy Bypass -File .\package.ps1`。不自动上传或发布。

## 打包内容

程序与 SciLexer 使用当前编译输出；BASS/BASS FX/tag DLL 随同打包，并校验五个核心 PE 文件均为 x64。语言、皮肤、外部编码器、默认便携配置和 LICENSE 来自仓库的分发输入，不复制开发机运行配置。程序内嵌的编译时间、Git 提交号和 EXE SHA-256 写入 `BUILD-INFO.txt`。

固定包含 `MusicPlayer2.exe`、`bass.dll`、`bass_fx.dll`、`tag.dll`、`SciLexer.dll`、`language/`、`skins/`、`Encoder/`、初始 `global_cfg.ini`、使用说明、LICENSE 和构建信息。

不包含开发机的 config.ini、remote-library.json、remote-cache、playlist、用户数据库、日志、PDB、obj、test-results、preserved-data 或旧构建目录。接收者自行配置服务器地址和账号所属 API Key；密钥继续由接收者自己的 Windows 用户加密保存。

目标电脑需安装 Microsoft Visual C++ x64 运行库。现有 x64 包的可选解码/编码插件限制沿用[运行依赖说明](../third_party/runtime/README.md)，本次不下载或升级第三方组件。
