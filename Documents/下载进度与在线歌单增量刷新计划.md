# 下载进度与在线歌单增量刷新计划

日期：2026-10-24。状态：已授权开发；当前阶段只本地验证、提交，不推送发布。

## 范围与行为

本期复用现有 `/api/v2/sync`，实现下载进度可视化与客户端增量应用。后续服务端成员变更协议独立规划，继续保留当前权限绑定、分页、失效订阅和必要的全量重置，不移除安全校验。

用户补充要求：播放器定时自动刷新。默认每 5 分钟检查；进入在线歌单页面时缓存立即展示并后台检查。已经载入服务器歌单时，即使媒体库页面关闭也继续定时检查；普通本地播放不额外启动服务器轮询。后台失败退避到 10／20／30 分钟，恢复成功后回到 5 分钟；手动刷新立即触发且不受退避限制。运行中的同步合并为同一任务，不叠加定时请求，不弹阻塞提示。配置或 Key 切换后取消旧任务并隔离其结果。

下载进度只影响显示，不写入真实播放位置或系统媒体时间轴：

| 状态 | 显示与交互 |
| --- | --- |
| 当前歌曲等待下载／校验 | 原播放条切换蓝色下载进度；显示字节、百分比及阶段；禁用定位、滑块和 AB 标记 |
| 正在播放，后台离线保存 | 保留播放条与定位，下沿叠加另一颜色的批量下载细条 |
| 无下载 | 正常播放进度；失败／取消后清除下载状态，保留原有错误反馈 |

批量进度按去重后的待下载音频字节加权，已存在且可验证的缓存跳过，封面不计入音频下载百分比。保持单并发；播放准备在曲目边界优先处理，正在进行的后台单首下载不承诺抢占／断点续传。未知总大小显示阶段，不伪造百分比。主界面、迷你模式、普通条与滑块条使用同一展示状态，悬停可查看大小、速度和批量计数。

同步只更新实际变化的歌单／行与封面，保留歌曲 UUID、内容哈希、歌单版本和订阅版本。仅游标续期时仍持久保存最新游标，但不重建音频播放队列／本地歌单；同步无变化时跳过重复资源检查。元数据改变复用音频，内容哈希改变按新内容缓存；播放中的同 UUID 旧音频允许延后切换，权限撤销仍及时执行现有失效策略。只在全部分页成功后提交快照，不保存部分结果。

## 实施文件

- `RemoteLibraryClient.h/.cpp`：进度回调、歌单版本、同步内容指纹和变化集合、按需封面更新。
- `RemoteLibraryManager.h/.cpp`：线程安全任务进度、前后台任务识别、离线批量汇总、物化指纹与按需写入。
- `Player.h/.cpp`：当前曲目准备状态、按 UUID 保持当前播放、当前远程队列差异应用。
- `CPlayerUIBase.h/.cpp`、`UIElement/ProgressBar.cpp`、`SliderProgressBar.cpp`、`Slider.h/.cpp`：统一进度绘制、提示和下载期间交互限制。
- `ServerLibraryDlg.h/.cpp`、`MusicPlayerDlg.cpp`：前台缓存展示、定时／手动共用同步、后台结果应用、选择与滚动位置保持。
- `UnitTest/`：原生进度／差异单元测试、HTTP 进度与分页 fixture、隔离桌面针对性验收；产物放 `test-results/`。
