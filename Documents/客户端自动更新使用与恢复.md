# 客户端自动更新使用与恢复

适用 Windows 10／11 x64，自 0.2.0 起提供自动更新。首次从 v0.1.0 升级需手动下载完整 `MusicPlayer2.zip`，解压到用户可写的本地目录。目标电脑仍需要 Microsoft Visual C++ x64 运行库。

## 检查与安装

“关于 → 检查更新”查询当前独立仓库的正式 Release。下载前显示版本、大小和发行说明，可以稍后或跳过该版本。启动检查默认沿用原有开关，每天最多一次，可在数据设置中关闭。手动检查不受每日间隔或跳过设置限制。

点击下载后显示大小、百分比和速度；此时可继续播放或取消。校验和目录预检完成后，点击“安装并重启”，程序会保存设置与歌单、停止播放并退出。独立更新器替换程序文件，启动新版本并等待版本、提交号及基础初始化确认；失败则恢复原程序。安装期间不要手动打开另一个播放器。

下载来自 `ShenYunyao1/MusicPlayer-for-Windows`，不需要音乐 API Key 或 GitHub 登录。支持环境变量代理和 Windows 当前用户静态代理；PAC-only 网络请设置静态代理或手动下载，不会自动绕过证书校验。

自动安装保留 `config.ini`、`global_cfg.ini`、`remote-library.json`、歌单、媒体与缓存，并保留当前便携／AppData 模式。语言、皮肤、编码器资源若有本地修改，会提示先备份并恢复原始文件。普通程序资源来自签名包；不会清空安装目录或删除未知文件。

## 失败与恢复

- 网络或校验失败：当前程序不退出；检查网络后重新下载，或打开错误窗口的“手动下载”。
- 无写权限／非本地固定磁盘／链接目录：首期不请求管理员提权，请移动完整程序到用户可写的本地固定磁盘目录，或手动安装。
- 其他播放器占用单实例锁：关闭该播放器后重试，不会自动结束它。
- 安装途中断电或强制退出：再次启动播放器会检查未完成事务并打开恢复入口。若主 EXE 缺失，直接运行安装目录内的 `MusicPlayerUpdater.exe --recover`。
- 恢复前退出该目录的播放器。更新器会从 `.musicplayer-update/backup/` 恢复旧程序；不要手动删除该目录中的 `journal.json` 和备份。恢复失败时保留目录，按错误信息排查文件占用／权限，或将官方完整包解压到新目录后手动保全原有数据。

检查与安装日志位于当前配置目录的 `updates/latest-update.log`，错误窗口可点击“查看日志”。日志不记录 Key 或个人配置内容。一次成功或恢复结束的程序备份保留到下次更新预检；更新不回滚个人数据，因此首期禁止不可逆配置迁移。

发行包还包含 `PROGRAM-FILES.json` 资源基线和 `BUILD-INFO.txt` 构建身份。请保留它们及独立更新器，不要只复制主 EXE。Ed25519 发行签名不等于 Authenticode，SmartScreen 提示可能仍出现。

## 开发、签名与发行

构建额外需要 Go 1.26 和 Python 3，均加入 PATH；MSBuild x64 Release 会调用 `scripts/build-updater.ps1` 生成固定名称 `build/MusicPlayerUpdater.exe`。`client-release.json` 生成忽略目录内的版本头，禁止手改生成文件。测试代码保留在 `UnitTest/` 和 `updater/`，产物与日志放 `test-results/`。

完整回归由 Actions 执行。开发者发布核验需要 Python 3 与支持 Ed25519 的 OpenSSL；脚本会尝试系统 PATH 或 Git for Windows 自带 OpenSSL。`publish.bat -Mode Release -Version 0.2.0` 仍执行干净工作区、版本／标签、权限及 Actions 门禁；正式 Release 现在必须有 ZIP、SHA-256、清单及 `.sig` 四个资产。

客户端签名公钥在 `updater/internal/trust/public.pem`，私钥只用于受信任标签发行作业的 `CLIENT_UPDATE_SIGNING_KEY` Secret。普通构建／PR 使用随机测试密钥，不接触正式私钥。维护者本地私钥备份为用户 SSH 目录中的 `musicplayer-client-release.pem`，仅本机用户与 SYSTEM 可读；它不在源码或发行包中。密钥轮换需过渡版本，不能直接替换公钥让旧安装失去更新能力。

验收命令：`cd updater; go test -timeout 90s ./...`，以及 `python UnitTest/test-client-release.py`、`python UnitTest/test-publish.py`、构建后的 `python UnitTest/test-package.py`。真实桌面启动／退出合同验证为 `python UnitTest/test-client-update.py --desktop`，执行前关闭其他播放器；它使用隔离配置，不代表音频播放验收。
