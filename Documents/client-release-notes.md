# MusicPlayer2 独立发行 0.4.0

本版新增对象级增量同步：连接支持新协议的 MusicServer 时，歌单增删曲目或调整顺序无需重新下载整个曲库快照，只按 UUID 批量补取缺少或变化的曲目信息。全部分页及曲目批次成功后才原子保存，失败不会写入部分歌单或推进游标。原有每小时自动检查、手动刷新、内容校验及播放状态保留继续有效。

授权撤回、无效订阅和需要重新同步的游标会先阻止旧快照离线恢复；完整验证成功后恢复使用。普通临时 503 保留已有有效缓存。包含同步重启后断网、批次失败、成员排序和权限隔离回归。

兼容固定服务器基线 0.16.2／schema 7；旧服务器未声明新协议时自动使用原协议。候选服务器另由 Actions 独立联调。本版服务器功能对应 MusicServer 0.19.0，服务器与播放器独立更新，个人配置和已校验音频缓存保留。

此前 0.3.1 功能：

本次更新：

- 修正 Actions 新增测试步骤的 YAML 缩进；0.3.0 候选未通过工作流解析，未公开 Release，保留标签记录。

- 下载歌曲时复用播放进度条，以蓝色显示下载字节与校验阶段；下载期间禁用定位。普通条、滑块和迷你模式共用状态。
- 播放时后台离线保存歌单，以橙色细条显示去重后待下载音频的字节进度；跳过已验证缓存，关闭歌单窗口后任务继续。
- 在线歌单默认每小时自动检查；首次缓存优先，手动刷新立即执行，重复检查合并。失败后按 2／4／6 小时退避，成功后恢复每小时。
- 同步继续使用现有增量协议和权限校验。游标续期不重写未变化的本地歌单；只更新变化的曲目行与资源，并保留当前曲目的 UUID 和播放流。
- 修正后台同步结果应用，确保订阅／分享失效、Key 失效及重新授权后正确更新播放队列。

本版不改变服务器协议或测试基线。播放器连接配置继续保存在用户的 `remote-library.json`，API Key 使用 Windows 当前用户加密；原位更新保留配置、歌单和缓存。

已有功能及安装说明：

基于上游 MusicPlayer2 2.78，支持 MusicServer `/api/v2`。本期兼容基线为服务器 0.16.2 / schema 7。

- 使用账户所属 API Key 访问全局曲库、个人歌单、公开订阅及指定账户只读分享。
- 支持分页与增量刷新、按需下载、内容校验、离线缓存，以及授权撤回和无效订阅状态。
- 修复 HTTPS 协议判断错误导致的连接测试 HTTP 400。
- 独立 Actions 验证、构建与发布 Windows x64 白名单包，附提交号、SHA-256 和发行清单。
- 新增签名自动更新：检查当前独立仓库的正式版本，确认后下载、校验、保存退出、替换程序并重启；失败时恢复旧程序，保留个人数据。
- 原生更新窗口显示下载进度，支持取消、稍后和跳过版本；启动检查每日最多一次，可在设置中关闭。
- 使用客户端专用 Ed25519 签名；版本界面与文件资源统一使用独立发行版本。
- 更新只覆盖程序文件，保留便携／AppData 配置、API Key、歌单和缓存；有修改的皮肤与语言资源会提示冲突。
- Windows 产物经 Ubuntu 再次校验；修复打包成功返回码与默认配置换行差异导致的误判。

下载 `MusicPlayer2.zip`，完整解压后启动其中的 `MusicPlayer2/MusicPlayer2.exe`。不要只复制 EXE；目标电脑需要 Microsoft Visual C++ x64 运行库。服务器地址填写根地址，API Key 由使用者自行配置。包内不包含个人账号、配置、歌单、缓存或测试数据。

v0.1.0 用户需要手动下载并完整解压本版本一次，此后可在“关于 → 检查更新”安装后续正式版本。自动安装支持 Windows 10／11 x64、用户可写的本地目录；无写权限时请手动升级。x86 仅做编译检查，暂不分发。Ed25519 发行签名不等于 Authenticode 签名，Windows 可能仍显示 SmartScreen 提示。
